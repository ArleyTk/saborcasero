# Rueda Libre y proyecto modular

## Descripción del proyecto

**Rueda Libre** es un sitio web desarrollado como proyecto académico, enfocado en el alquiler de bicicletas en Medellín. Su objetivo es ofrecer a los usuarios información sobre los tipos de bicicletas disponibles, las tarifas de alquiler, los recorridos y los medios de contacto para realizar una reserva.

El proyecto se desarrolló progresivamente, incorporando diferentes tecnologías y herramientas de desarrollo web, con el propósito de mejorar su estructura, diseño, funcionalidad y adaptación a distintos dispositivos.

## Tecnologías utilizadas

- **HTML5:** Estructura y organización del contenido de las páginas.
- **CSS3:** Estilos personalizados, diseño visual y efectos.
- **Bootstrap 5:** Implementación de componentes como tarjetas, barras de navegación, formularios y diseño responsive.
- **Tailwind CSS:** Exploración e implementación de utilidades para los estilos.
- **JavaScript:** Implementación de funcionalidades e interacciones en la interfaz.

## Funcionalidades implementadas

- Página de inicio con información general sobre Rueda Libre.
- Sección de servicios y tipos de bicicletas disponibles.
- Página de tarifas de alquiler y recorridos.
- Página de reservas con información de contacto y horarios de atención.
- Navegación entre las diferentes páginas del sitio.
- Diseño responsive para adaptarse a diferentes tamaños de pantalla.
- Implementación de tarjetas (Cards) para organizar el contenido.
- Formulario con modal de confirmación.
- Botón para cambiar entre temas visuales.
- Integración de Bootstrap y exploración de Tailwind CSS.

## Historial de desarrollo

El proyecto se desarrolló por etapas, realizando diferentes mejoras y cambios a lo largo del proceso:

1. **Estructura inicial (20 de octubre):** Creación de la estructura base del proyecto y organización de las carpetas.
2. **Desarrollo de páginas HTML (20 y 21 de octubre):** Implementación del contenido de las páginas, incluyendo inicio, tarifas y reservas.
3. **Estilos CSS (23 de octubre):** Incorporación de estilos personalizados y mejoras visuales.
4. **Organización del proyecto (26 de octubre):** Modificación de nombres de carpetas y reorganización de archivos.
5. **Mejoras de navegación y diseño (27 de octubre):** Implementación de la barra de navegación, cambios de imágenes y mejoras responsive.
6. **Implementación de tarjetas (28 de octubre):** Incorporación de tarjetas y ajustes para mejorar la presentación del contenido.
7. **Diseño responsive (28 de octubre):** Adaptación de la página para diferentes dispositivos y tamaños de pantalla.
8. **Integración de Bootstrap (30 de octubre):** Implementación de Bootstrap en las tarjetas, barra de navegación y formularios.
9. **Modal de confirmación (2 de noviembre):** Incorporación de un modal para mejorar la interacción con el formulario.
10. **Exploración de Tailwind CSS (4 de noviembre):** Implementación y pruebas de Tailwind CSS.
11. **Cambio de temática (5 de noviembre):** Transformación del proyecto original *Sabor Casero* en *Rueda Libre*, adaptando el contenido y la interfaz al alquiler de bicicletas.
12. **Mejoras finales (5 de noviembre):** Incorporación de un botón para cambiar entre temas y ajustes generales del proyecto.
